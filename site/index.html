Windows 3.1 Minesweeper.
Windows 3.0 underneath.

The game is Microsoft's original, unmodified WINMINE.EXE. The open-source WM88 bridge translates file reads in memory; Windows and the game are not reimplemented. Click once and play it here.

This browser run emulates an 80286, not an 8088. It is a compatibility and gameplay demo. The 8088 result is the real Tandy 1000 EX run, shown in the repository and video.

What this does. This site hosts no Microsoft software. When you click, your browser downloads public reference disk images of PC DOS 3.20 with Windows 3.0 and of Windows 3.1 (about 10 MB over the wire, about 29 MB unpacked) from the public Foxlum PCjs archive on GitHub, plus the PCjs ROM files from the PCjs repository. Every file is checked against a pinned SHA-256, the original Minesweeper is cut from the Windows 3.1 image and must match a pinned 27,776-byte hash, and everything is combined in this tab's memory only. Nothing is uploaded or stored. You are responsible for using media you are entitled to use.

  2. Fetch and verify the Windows 3.0 reference disk
  3. Fetch and verify the Windows 3.1 reference disk
  4. Extract WINMINE.EXE, check its hash, build the guest disk
  5. Boot: DOS, the bridge, its tests, then Windows
Use my own files instead (nothing is downloaded except the PCjs ROMs)

1 · Wait for boot

DOS loads the bridge and runs the TEST88 and RTEST2 suites, then opens the game. Look for T88PASS and 0123456789ABCDERT2PASS.

2 · Play the original

Click inside the screen. Left-click reveals; right-click flags; F2 starts a new game. The guest mouse is relative: steer its visible arrow to a cell, then click.

3 · Reload to reset

Nothing is saved. Reloading the page discards the session and starts fresh.

Original EGA display: the dark-red digit segments are dithered by the stock display driver. Their shapes match the original game bitmap exactly. If a click first focuses the emulator, click again.

What this proves, and what it doesn't

The browser executes the original DOS, Windows 3.0 and Windows 3.1 Minesweeper code on an emulated 80286. WM88TSR translates the known 27,776-byte specimen and the 361-byte SHELL.DLL shim supplies ShellAbout. A working 286 run does not prove 8088 instruction compatibility or timing.
